Pas de connexion

Buildex a besoin du serveur pour afficher quoi que ce soit d’exact. Rien n’est montré depuis le cache : un état de build périmé serait pire qu’une page vide.

  • Les builds déjà lancés continuent sur le serveur, sans vous.
  • Les liens de téléchargement d’APK restent valables une fois revenu.
  • Si le réseau est bon, c’est peut-être le service qui est arrêté.
