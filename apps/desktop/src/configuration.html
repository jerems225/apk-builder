Cette application affiche l’interface servie par votre serveur Buildex. Elle ne compile rien elle-même — tout se passe côté serveur.

Le préfixe https:// est facultatif. L’adresse est vérifiée auprès de /healthz avant d’être enregistrée : mieux vaut la refuser ici qu’afficher une page blanche.
